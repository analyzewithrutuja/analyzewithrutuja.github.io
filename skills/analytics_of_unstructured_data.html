01
Text Preprocessing Fundamentals

Raw text is messy. Every NLP pipeline starts by breaking it down, cleaning it, and normalizing it into a consistent form.

Tokenization
sentence → 3 tokens
Stopword removal
stopwords stripped
Stemming
running → run
Lemmatization
better → good
Parts of speech tagging
DET · NOUN · VERB
Text normalization
Hi!! / HI / hi → hi
text → tokens → lowercase → remove stopwords → stem / lemma ← preprocessing pipeline
02
Text Representation & Encoding

Models need numbers, not words: turning cleaned text into vectors that capture frequency and importance.

One-hot encoding
cat → [0,0,1,0,0]
Bag of words
word : count pairs
N-grams
the cat, cat sat
TF-IDF
rare .82 · the .02
TF-IDF(t,d) = tf(t,d) × log(N / df(t))
03
Word Embeddings

Instead of counting words, embeddings place them in a continuous space where meaning and context shape the geometry.

Embedding space (vector arithmetic)
king−man+woman≈queen
Word2Vec: CBOW
context → center
Word2Vec: Skip-gram
center → context
Cosine similarity
cos(θ) = 0.82
GloVe
co-occurs(ice, cold)
cos(θ) = (A · B) / (‖A‖ ‖B‖) ← word similarity

Text generation

Perplexity

05
Information Extraction

Pulling structured facts (people, places, relationships) out of unstructured sentences.

Named entity recognition

Chunking

Dependency parsing
subj(cat, sat)
Coreference resolution
she = Maria
B-PER I-PER O O B-ORG O ← BIO tagging scheme
06
Text Classification & Sentiment

Turning a block of text into a label: spam or not, positive or negative, this topic or that one.

Naive Bayes classifier

Sentiment analysis

Spam detection

Topic modeling (LDA)
sports 60% · politics 25%
P(class | doc) = P(doc | class) × P(class) / P(doc)
